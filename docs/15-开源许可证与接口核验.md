## Uptime Kuma 接口边界核验

[上游 Internal API Wiki](https://github.com/louislam/uptime-kuma/wiki/Internal-API)明确警示该 API 主要供应用自身使用，不保证第三方集成且可能破坏性变更；同页列出 Push endpoint `/api/push/<pushToken>`、status/message/ping 参数。规格因此把它隔离为可选 `UptimeKumaPushAdapter`，仅发 heartbeat；不调用 Socket.IO，不读写 monitor 配置，不同步事故。

API contract 检查按选定 Uptime Kuma 版本运行。若接口变更，默认关闭 adapter、保留 Dawnwatch 功能；不可悄悄依赖未承诺的内部接口。Push Token 位于路径，需防止 access logs、HTTP tracing、代理日志输出原值。

## Agent/模型接口核验

- LangGraph 使用 Python `StateGraph`/节点边/compile 和 checkpointer；保存结构化最小状态，`thread_id` 固定到 AgentRun ID。实现依赖签名以锁定版本的 reference 为准。
- Python 内部 API 只由 Java 调用；不直接暴露给 Vue 或公网。
- 模型厂商 API 的数据保留、训练使用、区域和日志策略按实际供应商/账号方案单独核验；不会由 LangGraph MIT 许可覆盖。
- 执行依赖扫描生成 SBOM 和许可证报告；AI 模型权重/Tokenizer 等均逐一登记来源、版本和许可证。
