# 16｜Dawnwatch UI/UX 设计规范

依据用户于2026-10-21提供的设计说明实施。基线为G5提交 `22b696f`；本轮在原有业务与权限模型上重构界面。

## 产品与视觉

企业级AI智能运维/故障诊断平台，Dark-first。参考Linear的视觉秩序、Grafana的数据组织和Datadog的事件处置习惯，不复制品牌元素。无霓虹大屏、无装饰性渐变/发光、无聊天机器人替代监控。字体使用系统UI与等宽字体，无外部字体请求。

Light使用语义token切换为浅背景/白面板与可读的状态前景；主题仅保存非敏感偏好，不持久化登录token。状态始终包含图标和文字，不能只用颜色。

## 技术与共享层

Vue3+TypeScript+Vite，TailwindCSS4、shadcn-vue手动集成方式（Reka UI原语、CVA与cn工具、自有可维护组件源码），Apache ECharts按需模块，Lucide Icons，Pinia共享主题/时间范围/导航状态，Vue Router。保留现有会话仅内存与服务端鉴权。

先建立tokens、Button/Badge/Input/Dialog、页面标题/状态/筛选/表格排序/图表容器，再实现页面。所有网络、Loading、Empty、Error均有真实状态；更新中保留旧数据但标注时间，失败不能伪装刷新成功。支持reduced-motion、键盘焦点、跳到正文、弹窗焦点锁/ESC与移动导航。

## 六个工作区

1. **运维总览 /overview**：当前快照指标、真实状态分布、选定服务的检查延迟/结果、范围内事件和待处理入口。图表带文本等价信息、数据时间与样本范围；没有数据时留空态。
2. **服务监控 /targets**：可搜索/排序/分页的目标表，目标详情保留检查、历史、网络、ACL、Kuma；当前健康不能冒充历史SLO。
3. **告警与事件中心 /incidents**：异常进度与正式事故分开，服务/状态/时间范围筛选及服务端排序分页；事件详情采用时间线主区+处理上下文侧栏，版本/操作理由/审计保持原约束。
4. **AI诊断 /diagnosis、/agent-runs/:id**：任务索引和证据工作台，展示结论、引用、未知、建议、节点记录及审批；不是聊天页面。主区事实/推断与证据分栏，人工决策可清楚辨认。
5. **Agent执行与审批 /agents**：按真实任务状态筛选执行、人审、待线下处理任务；列表受原报告可读权限和目标ACL双重约束，纯管理员的投递恢复仍只展示原有元数据权限。
6. **运维知识库 /runbooks**：可搜索/排序的已授权手册目录与目标筛选，保留草稿/发布/不可变版本和引用锚点。

## 全局交互与数据边界

- Ctrl/Cmd+K打开搜索：只查询当前身份可见的服务、事故、手册，最少2字符，服务端查询，不以首页20条冒充全局。
- 共享时间范围用于事件/任务/检查数据；当前服务快照、知识库不伪装成历史聚合。范围与数据上限明确标注。
- 表格排序使用服务器允许列表，筛选计数和分页来自同一查询，过滤变更回到第一页。
- Dashboard图只画真实接口返回的数据；无样本不生成假曲线/假延迟，未知不计正常。最多100条检查样本时明确标注。
- Agent节点只显示已保存状态与完成时间；PENDING不伪造“正在执行某工具”。工具/证据来源仅展示实际冻结的检查记录、手册引用及节点记录，无虚构执行耗时或命令。
- mock不展示真实模型置信度；实际provider如返回评分，明确是模型自报、未校准，不冒充准确率或根因概率。
- 审批与线下回填继续要求ON_CALL+目标操作ACL、版本、理由/幂等；批准不执行命令，不自动解决事故。

## 实施与验证

优先总览、事件详情、AI诊断工作台；其余页面在同一主题/组件体系下接入真实交互。为支持搜索/筛选新增只读API时先验证ACL、分页/排序及时间边界，不改变迁移或用户数据。

验证：类型检查/构建、必要的查询/数据变换测试、真实本机fixture浏览器（深浅主题、键盘搜索、筛选/排序、错误/空状态、窄屏、审批/观察员隔离），一次独立整体评审。同步启动指南的安装/页面入口和操作说明；真实用户服务、数据库保持原样。

## 处置导航与细节修正（2026-10-21）

- 共享Select使用已有Reka原语，触发器、浮层、选中/高亮/禁用/焦点均使用语义token，不依赖操作系统原生白色菜单。支持键盘和屏幕阅读器标签，业务空字符串筛选与数字版本值保持原类型。
- 顶部改为当前工作页面标题、返回按钮及可关闭工作页签；同一详情的查询/锚点变化不重复开页签。首页固定，关闭非当前页签不导航，关闭当前页签选相邻工作页。左侧按服务/事件/诊断/审批分组，选中记录后才显示对应的当前详情与子页面入口；管理项按角色隐藏。
- 事件和诊断顶部使用可见的“当前处理步骤/下一步处理”操作条，依实际阶段、恢复证据和当前权限给出动作。事件理由与审阅/线下回填在当前页面弹窗完成；不改变原版本校验、理由、幂等和审计要求。投递失败说明与重试入口前置。
- 列表筛选/排序/页码和滚动位置仅存本登录会话。详情返回保存的调用来源，不固定跳首页；登录恢复只接受允许列表中的内部地址。未知的已登录路由显示404，无法安全续接的登录地址退回概览。整页刷新仍会清除内存会话；重新登录恢复允许的详情地址，退出/换身份清空工作状态。未提交表单不跨页持久化。
- hash变化只触发一次定位/打开审阅；普通数据轮询不抢滚动位置。浏览器后退离开审阅hash会关闭弹窗，前进重新打开，Esc可关闭。
- 本轮依据本项目规范实现后台多页签交互，没有读取或复用其他项目源码；未增加依赖、迁移、启动变量或持久化token。
